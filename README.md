# CivReplay releases

Installers for **CivReplay**, a desktop app that reads Civilization VI save files and uploads game statistics to
[civgg](https://civgg-five.vercel.app).

## Download

Get the latest `CivReplay_x.y.z_x64-setup.exe` from the [Releases](../../releases) page.

The installer is not code-signed (no paid certificate), so Windows SmartScreen may show a warning: click
**More info**, then **Run anyway**. Each release links to its VirusTotal scan and lists the SHA-256 of the file.

## What it does

- Reads the Civ VI save files you select on your computer.
- Sends game statistics (no personal data beyond in-game names and Steam-linked player identity) to civgg over HTTPS.
